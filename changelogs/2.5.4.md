# v2.5.4（2026-10-10）

- **随机轮询**：状态与战绩订阅新增共用的随机时间范围，默认 ±10 秒；每轮独立抽取，基础间隔 60 秒时等待 50～70 秒，最短 1 秒，填 0 恢复固定间隔。页面显示随机范围和实际确定的下次轮询时间，刷新不会重新抽取。
- **分钟冷却**：账号冷却改为 `account_cooldown_minutes`，默认 5 分钟，配置范围 0～1800 分钟（最多 30 小时），后端同步限制上限。移除旧版秒制配置及兼容迁移，升级后需重新设置冷却时间。
- **QQ 登录错误处理**：系统浏览器启动失败时尝试已安装的 Playwright Chromium；分别提示浏览器缺失、Linux 系统库缺失、网络错误、超时和二维码未加载，后台保留脱敏诊断。修复宿主桥接把登录终止错误当作临时请求失败，导致页面持续轮询的问题。
- **文档与构建**：补齐 Linux / Docker 浏览器安装说明、2.5.4 升级步骤和验证范围；前端源码校验统一换行，避免 Windows / Linux 的校验值差异，发布产物同步更新。
- **验证**：八套离线测试共 499 项全部通过（含 31 项订阅回归和 43 项扩展回归），Ruff、JavaScript 语法、版本与文档链接、前端产物同步以及 Node 登录轮询和回顾时间轴检查通过。Playwright 本地模拟页面验证 1440×1000 / 390×844 的随机范围显示、刷新保持截止时间、固定间隔及暂停状态；未在用户远端实测 QQ 扫码或发送真实消息。
