# 王者营地数据查询（astrbot_plugin_gok）

通过**王者营地官方接口**查询王者荣耀玩家数据的 AstrBot 插件。

插件使用自己的营地登录态查询数据：先在插件页面用微信扫码登录王者营地，
之后所有查询都由插件直接请求 `kohcamp.qq.com`，**不依赖任何第三方数据接口、
不需要申请任何 API 令牌**。

> 本文档所述功能对应 v2.4.1。相比 1.x，数据源已从第三方接口完全改为营地直连。

---

## 功能

| 能力 | 说明 |
| --- | --- |
| 战绩查询 | 最近对局列表：英雄、KDA、评分、MVP/金牌/巅峰分变化、时长、对局段位 |
| 玩家资料 | 段位与星数、赛季场次/胜场/胜率、排位与巅峰评分、巅峰积分、金牌数、本赛季常用英雄 |
| 对局详情 | 单场对局的双方十人面板：等级、KDA、经济、输出、承伤、英雄战力 |
| 战绩锐评 | 把最近对局交给对话模型，生成一句吐槽（需开启并配置模型） |
| 角色名称映射 | ID 查询成功自动保存游戏角色名，管理页可修改显示名称，聊天中可查看和按名称查询 |
| 多账号 | 可登录多个营地账号，触发频控时自动切换 |
| 登录态检测 | 管理页一键逐个检测所有账号，区分有效、失效、频控和网络异常 |
| 交互战绩 | 资料和战绩使用独立按钮，战绩列表使用营地图片资源，点击一场查看双方详情 |

## 安装与启用

1. 把插件目录放入 `AstrBot/data/plugins/astrbot_plugin_gok`。
2. 在 AstrBot 管理面板 → 插件 中重载/启用插件。
3. 依赖：`aiohttp`、`aiosqlite`、`aiofiles`、`cryptography`
   （`cryptography` 已随 AstrBot 安装，一般无需额外处理）。
4. 打开插件页面 **王者营地查询**，用微信扫码登录。

### 扫码登录

管理面板 → 插件 → 王者营地查询 → 「获取登录二维码」，用**微信**扫码并在手机上确认。
登录成功后登录态保存在 `data/plugin_data/astrbot_plugin_gok/camp_auth.json`，
后续查询无需重复登录；登录态失效时回到该页面重新扫码即可。

> 登录态等价于你的营地账号凭证，请勿把 `camp_auth.json` 分享或提交到仓库。

## 指令

指令参数既可以是**营地 ID**（5~15 位数字），也可以是**已保存的角色别名**。

### 查询

| 指令 | 说明 |
| --- | --- |
| `功能` / `帮助` / `王者功能` / `王者帮助` | 固定以文本显示功能说明 |
| `战绩 [ID/别名] [场数]` | 最近对局战绩，默认 10 场，最多 25 场，按配置输出图片或文本 |
| `资料 [ID/别名]` | 段位、赛季胜率、本赛季常用英雄，按配置输出图片或文本 |
| `对局 [ID/别名] [序号]` | 第 N 场对局的十人详情与出装，序号从 1 开始，按配置输出图片或文本 |

### 角色名称映射

| 指令 | 说明 |
| --- | --- |
| `角色查看` | 固定以文本列出全部已保存角色名称与营地 ID |

使用数字营地 ID 查询资料、战绩或详情成功后，插件自动保存游戏角色名。
名称的修改和删除仅在管理页进行；管理员修改过的显示名称不会被自动同步覆盖，
原始游戏角色名仍会更新。升级时保留已有名称映射，不恢复玩家数据缓存。

### 管理页面

* **检测全部登录态**：每个账号独立请求自己的营地资料，不自动换号；无效账号停止参与查询，
  网络异常和频控显示为暂无法确认，避免把它们误判为登录过期。
* **玩家查询**：同一个营地 ID 对应「查询资料」「查询战绩」两个按钮。战绩使用已有聊天图片
  模板的深色/金色布局，展示头像、英雄、KDA、评分、荣誉、时长和段位。点击一场战绩进入详情，
  再返回列表时重新实时查询；按对局标识定位，避免列表更新后查看到另一局。
* **营地图片**：使用接口提供的头像、英雄图片、MVP、奖牌与背景。资料和战绩顶部使用排位模块
  返回的段位图、星级图；详情按每位玩家的 `finalEquips` 展示装备及名称，附带召唤师技能。
  页面不再展示“更多营地图片”。

### 账号

| 指令 | 说明 |
| --- | --- |
| `营地登录` | 查看登录状态与扫码入口提示 |
| `营地账号` | 列出已登录账号及其冷却状态 |

## 配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `prefix.enable` / `prefix.text` | `false` / `王者` | 指令前缀，避免与其他插件冲突 |
| `battle_limit` | `10` | 战绩默认显示场数 |
| `query_output` | `图片` | `图片` / `文本`，仅影响战绩、资料、对局及其同义指令；文本只显示关键信息 |
| `account_cooldown` | `300` | 账号被频控后的冷却时长（秒） |
| `request_timeout` | `15` | 单次接口超时（秒） |
| `tls_verify` | `true` | TLS 证书校验，建议保持开启 |
| `comment.enable` | `false` | 战绩成功发送后是否自动跟发锐评 |
| `comment.prompt` | 一句话锐评提示词 | 修改锐评风格和长度，对局数据自动附加 |
| `comment.select_provider` | 空 | 锐评使用的模型，留空用会话默认模型 |
| `image.format` | `jpeg` | 输出格式 `jpeg` / `png` |
| `image.device_scale_factor` | `1.3` | 渲染清晰度 |
| `image.jpeg_quality` | `100` | JPEG 质量 |

## 工作原理

图片指令会先读取插件的 HTML 模板内容，然后调用 AstrBot 自带的 `Star.html_render()`。
图片服务不可用时自动回退到查询结果文本；功能、角色查看固定使用文本。
开启 `comment.enable` 后，战绩图片或文本成功发送后自动追加一次锐评；无需单独发送锐评指令。
`comment.prompt` 可修改提示词，实际展示的对局数据自动附加到提示词之后。

```
指令 ──► GokService（实时查询，不缓存）
            ├─► CampDataApi ──► CampClient ──► kohcamp.qq.com
            │        （encodeParam 加密、响应解密、错误码、换号重试）
            └─► GokStorage（SQLite：仅角色别名）
```

* **加密协议**：请求头 `encodeParam` = XXTEA(`{timestamp,nonce}`, 密钥 = `userKey`)；
  未登录时用 `specialEncodeParam` = RSA-PKCS#1 v1.5（1024 位，分块）。
  响应头 `campencrypt: true` 时用同一个 `userKey` 做 XXTEA 解密。
* **登录流程**：`getwxsdkticket` → 微信 `qrconnect` 取二维码 → 轮询 `l/qrconnect`
  → `user/login` 换 `userId`/`token`/`encodeRes` → 从 `encodeRes` 解出 `userKey`。
* **实时翻页**：营地战绩接口提供 `hasMore` + `lastTime` 游标，插件每次从最新战绩
  开始按游标翻页，每页间隔 400ms 以防频控。
* **实时查询**：不落库、不聚合、不增量同步；营地侧数据一变，下一次查询就能看到。

```
│   ├── template.py          # 模板加载（强制自动转义）
│   ├── webui.py             # 插件页面 API

```

## 自测

离线自测（不需要 AstrBot 运行环境，不访问外部网络；分块响应测试使用本机 HTTP 服务）：

```bash
cd data/plugins/astrbot_plugin_gok
python tests/run_all.py
```

三个套件分别覆盖：

| 套件 | 内容 |
| --- | --- |
| `tests/test_core.py` | XXTEA（与 Node 参考实现逐字节比对）、RSA 分块加密、段位换算、英雄目录、营地响应解析、SQLite 读写、并发扫码、实时读取与 HTTP 分块响应 |
| `tests/test_plugin.py` | 用宿主 API 桩验证插件装配、页面路由注册、指令分发、参数解析、前缀处理与错误降级 |
| `tests/test_templates.py` | 用样例数据真实渲染全部 HTML 模板，并验证自动转义没有失效 |

真实接口联调（需要你本人用微信扫码，仅在你主动运行时执行）：

```bash
python tests/live_smoke.py
python tests/live_smoke.py 489048724
python tests/live_smoke.py 489048724 --auth <camp_auth.json>
```

它会申请登录二维码、轮询扫码状态，登录成功后查询该账号的资料与最近战绩并打印结果，
用于验证加密协议与字段解析在真实数据上是否正确。登录态只写入临时目录。

## 常见问题

**查询提示「尚未登录王者营地」**
先在插件页面扫码登录；若刚登录仍提示，检查 `data/plugin_data/astrbot_plugin_gok/camp_auth.json`
是否存在且非空。

**提示「该召唤师隐藏了个人战绩」**
对方在营地里关闭了战绩公开，插件无法绕过。
插件会读取角色资料里的 `hideMatch` 标记来准确判断这种情况 ——
营地对隐藏战绩**不会返回错误码**，而是返回一个空列表，因此单看接口返回是分辨不出来的。

**提示「操作过于频繁」**
营地侧频控。再登录一个营地账号让插件自动切换，或隔一会儿再查。

**图片发送失败**
检查 AstrBot 的文转图（t2i）服务是否可用；可把 `image.format` 改为 `png` 或调低清晰度重试。

**营地改版后查询失效**
营地接口与加密参数可能变动。相关常量集中在 `core/camp_client.py`、
`core/camp_login.py` 与 `core/camp_crypto.py`，便于对照更新。
