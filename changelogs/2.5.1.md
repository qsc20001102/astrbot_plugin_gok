# v2.5.1（2026-10-09）

- **AI 分析缓存**：成功结果按对局唯一 ID `game_seq` 写入 SQLite，网页和指令优先复用；默认保留 150 天，可配置，读取不会延长寿命。启动、每小时及读取时清理过期结果；同场并发避免重复模型调用，失败和格式不合格的结果不落库。
- **分析入口**：单局详情顶部依次显示“分析本场”“分析结果”“清除缓存”，按缓存是否存在切换可用状态；进度与结果位于公共区域，不依赖回放页加载。“地图回顾”标签更名为“对局回放”。
- **订阅推送**：新增状态/战绩订阅、完整会话 ID 路由与 SQLite 去重游标。状态只在 `0↔1/2` 时推送，`1↔2` 不推送，查询失败或状态缺失不误报离线；战绩只推最新已完成对局，故障恢复不补推中间遗漏记录。首次关联建立基准，没有接收会话时暂停轮询。
- **订阅页面与指令**：新增“订阅系统”导航，包含订阅状态、订阅战绩、会话推送三个模块，显示轮询时刻与最新数据，支持目标增删及每会话多个订阅。新增 `订阅状态`、`订阅战绩`、`查看订阅`、`取消订阅`；状态和战绩轮询默认 60 / 120 秒，可分别配置。
- **资料与功能图片**：统一解析当前角色的 `gameOnline`，网页、资料图片及文本展示离线/在线/游戏中/未知；“功能”与“帮助”加入图片/文本输出配置，采用简约浅色指南，渲染失败回退完整文本。
- **页面切换**：统一查询、详情及管理页标题栏与外层留白，详情样式限定在查询页，切换导航回到顶部，固定滚动条占位，修复页面偏移。
- **文档与升级**：补齐 2.5.1 升级步骤、缓存和订阅数据边界、完整会话 ID、消息格式、故障恢复与公开 AppID 告警说明；版本声明统一为 2.5.1。
- **验证**：八套离线测试共 464 项全部通过（含 20 项订阅回归），Node 时间轴、Ruff 与前端构建同步检查通过；Playwright 本地桥接验证缓存、订阅和四种宽度的页面切换。模型与主动发送使用测试桩，未重新登录、未实发真实会话消息、未验证用户远程部署。
